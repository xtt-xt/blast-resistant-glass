## ✨ 简介

**防爆玻璃** 是一款网易基岩版 Minecraft 模组，添加了 **18 种防爆玻璃方块**。爆炸抗性和硬度均与**黑曜石**相同，完美保护你的建筑免受 Creeper、TNT 等爆炸威胁。

- 🛡️ **18 种颜色** — 包含透明及 17 种染色防爆玻璃
- 💥 **黑曜石级防护** — 爆炸抗性与硬度均与黑曜石相同
- 🎨 **兼容材质光影** — 支持各类材质包和光影效果

## 🛠️ 合成配方

### 熔炼配方

```
原版玻璃 + 燃料 → 防爆玻璃
```

将原版玻璃放入熔炉烧炼即可获得防爆玻璃。

### 染色配方

```
防爆玻璃  防爆玻璃  防爆玻璃
防爆玻璃  染料      防爆玻璃
防爆玻璃  防爆玻璃  防爆玻璃
         ↓
      染色防爆玻璃 × 8
```

用 8 个防爆玻璃和 1 个染料合成对应颜色的染色防爆玻璃。

### 遮光配方

```
空      紫水晶    空
紫水晶  防爆玻璃  紫水晶
空      紫水晶    空
         ↓
      遮光染色防爆玻璃 × 2
```

用 4 个紫水晶和 1 个防爆玻璃合成遮光染色防爆玻璃。
